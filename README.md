# Tastsu-Astro-Tool
TATSU es una herramienta web (un solo archivo .html) que asiste al astrónomo observacional en la planificación y ejecución de sesiones de fotometría de cuerpos menores del Sistema Solar: asteroides, cometas y TNOs. No requiere instalación ni conexión a internet para su funcionamiento local. Basta con abrir el archivo en cualquier navegador
