### Descripción
TATSU es una herramienta web (un solo archivo `.html`) que asiste al astrónomo observacional en la planificación y ejecución de sesiones de fotometría de cuerpos menores del Sistema Solar: asteroides, cometas y TNOs.  

### Funcionalidades
1. Tiempo de permanencia del cuerpo dentro del FOV del equipo en una serie de capturas.  
2. Tiempo máximo de exposición para obtener una impronta oblonga con longitud 1,5 veces el ancho de la impronta.  
3. Tiempo máximo de exposición para obtener una impronta oblonga con longitud 2,0 veces el ancho de la impronta.  

### Aplicaciones
- Fotometría de asteroides/cometas muy veloces.  
- Fotometría de cuerpos menores con magnitudes muy débiles.  
- Planificación de los tiempos de trabajo para cada serie de capturas durante una observación.  

### Instalación
No requiere instalación ni conexión a internet.  
1. Descarga el archivo `TATSU.html`.  
2. Ábrelo en cualquier navegador moderno (Chrome, Firefox, Edge, Opera).  

### Ejemplos de uso
- Calcular el tiempo máximo de exposición para un asteroide rápido.  
- Planificar la duración de una serie de capturas para un cometa débil.  
- Optimizar la sesión de observación con parámetros claros.  

### Referencia
Proyecto basado en planilla Excel, creada por Carlos Colazo, para Proyecto GORA (Grupo Observación de Rotación de Asteorides)
[AOACM](https://aoacm.com.ar/gora/viewtopic.php?t=104)*  

### Origen del nombre

### Description
TATSU is a web tool (a single `.html` file) that assists the observational astronomer in planning and executing photometry sessions of minor bodies of the Solar System: asteroids, comets, and TNOs.  

### Features
1. Calculates the time the object remains within the FOV of the equipment during a series of captures.  
2. Maximum exposure time to obtain an elongated imprint with a length 1.5 times the width of the imprint.  
3. Maximum exposure time to obtain an elongated imprint with a length 2.0 times the width of the imprint.  

### Applications
- Photometry of fast-moving asteroids/comets.  
- Photometry of faint minor bodies.  
- Planning exposure times for each capture series during an observation.  

### Installation
No installation or internet connection required.  
1. Download the `TATSU.html` file.  
2. Open it in any modern browser (Chrome, Firefox, Edge, Opera).  

### Usage examples
- Calculate maximum exposure time for a fast asteroid.  
- Plan capture series duration for a faint comet.  
- Optimize observation sessions with clear parameters.  

### Reference

[AOACM](https://aoacm.com.ar/gora/viewtopic.php?t=104)*
